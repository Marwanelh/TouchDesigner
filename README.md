# TouchDesigner Experiments

A collection of reusable TouchDesigner components and visual assets for interactive-media and computer-vision experiments.

## Components

- Face detection and tracking
- Hand tracking
- Image classification
- Image segmentation
- Image embeddings
- Face-filter example
- Clamp math utility

The repository also includes 2D and 3D point-cloud assets based on the 42 Bangkok KMITL logo.

## Repository structure

- `toxes/` — packaged TouchDesigner components
- `42_bangkok_kmitl_logo_pointcloud.ply` — point-cloud asset
- `42_bangkok_kmitl_logo_pointcloud_3D.ply` — 3D point-cloud asset

## Usage

Download the required `.tox` component and import it into a compatible TouchDesigner project. The face-filter file demonstrates how the tracking components can be combined in an interactive visual workflow.

## Status

This repository is an evolving collection of experiments and reusable building blocks.
